RTH_IO_PRO 重构版 · 企业级输出库

零依赖 · 跨编译器
为 C++ 打造的高性能格式化输出

rth_out_pro 是基于 rth_io_pro 全面重构的现代 C++ 输出库。它将运行时流式输出、 编译期常量拼接与高速缓冲输出彻底解耦为三个独立模块，按需启用， 在 40 种编译器平台上提供系统调用级别的极致性能。

C++11+ 标准要求 40 种编译器支持 3 种输出模式 0 依赖 · 0 堆分配
REFACTOR HIGHLIGHTS

从「能用」到 「工程化」 的跃迁

重构后的版本保留了 rth_io_pro 在跨编译器与系统调用层面的极致优化， 同时通过架构解耦、命名空间治理与健壮性修正，使其真正适合作为企业级基础设施组件。

01 / ARCHITECTURE

三模式解耦架构

运行时输出、编译期常量、高速缓冲三大能力拆分为独立模块，通过顶层宏精确控制启用。嵌入式场景可仅启用 fast_out，将代码体积压缩至最小。

02 / NAMESPACE

命名空间隔离

所有实现细节收归 out_rth 总域，对外仅暴露 rttype::out_t 轻量标记类型，彻底解决 rth_io_pro 中 rttype 与用户代码的命名污染问题。

03 / COMPATIBILITY

编译器兼容性基线

要求 C++11 及以上以启用 constexpr 常量输出，但底层 writer() 仍继承 40 种编译器的汇编级优化，覆盖桌面、ARM、国产与历史平台。

THREE OUTPUT MODES

三种模式，各司其职

通过 rth_out_pro_runtime_normal_out、rth_out_pro_constant_out、rth_out_pro_runtime_fast_out 三个宏开关，按需裁剪你的输出能力。

runtime_normal_out

流式输出

最接近 std::cout 的使用体验，但性能高出数倍。每次 operator<< 直接触发 writer() 系统调用。

  • 手写 lltoa / ulltoa，比 sprintf 快 3-5 倍
  • 浮点 6 位小数截断 + 尾零消除
  • 指针格式化为固定宽度十六进制
适用：调试日志 · 交互式 CLI · 嵌入式终端
constant_out

编译期常量拼接

最具技术含量的模块，允许在 constexpr 上下文中完成字符串格式化，零运行时开销。

  • constantout_t<N> 模板追踪容量，编译期推断长度
  • constexpr 版本 lltoa / ulltoa，无 UB
  • 支持 + / * / << 三种组合操作符
适用：编译期日志 · 静态资源表 · 模板元编程
runtime_fast_out

缓冲式高速输出

融合前两者优势：编译期已知容量的固定缓冲区 + 运行时流式追加，最后一次性刷出。

  • fastout_t<N> 栈缓冲区，零堆分配
  • << out 触发单次 writer() 调用
  • 每线程独立缓冲，无锁竞争
适用：高频交易日志 · 游戏引擎 · 服务端访问日志

// 1. 处理 INF / NaN / 负零
if (a != a)      → "NaN"
if (a > LDBL_MAX) → "INF" / "-INF"
if (a == -0.0L)   → "0"

// 2. 跨平台正确获取 long double 上限
#define LDBL_MAX_RT ((long double)__LDBL_MAX__)

// 3. 浮点转 6 位小数使用四舍五入而非截断
unsigned long long frac6 = (unsigned long long)(frac * 1000000.0L + 0.5L);

// 4. 进位溢出处理：ip 为 ULLONG_MAX 时回退为 INF
if (frac6 >= 1000000ULL) {
    frac6 = 0;
    if (ip == 0xFFFFFFFFFFFFFFFFULL) { /* 回退为 INF */ }
    ip++;
}

QUICK START

快速上手

三个模式可独立或组合使用，编译时通过宏开关控制裁剪。

// 示例代码

main.cpp 
#include <rth_out_pro>

int main() {
    // 模式一：流式输出
    rttype::out << "Hello, "
               << "rth_out_pro!"
               << rttype::endl;

    // 模式二：编译期常量
    constexpr auto banner =
        rttype::constantout<64>{}
        << "== rth_out_pro v2 ==";

    // 模式三：高速缓冲
    rttype::fastrt::fastout_t<256> buf;
    buf << "PID=" << 1234
        << " STATUS=" << "OK";
    buf << rttype::fastrt::out;

    return 0;
}

// 编译选项

terminal 
# 启用全部三模式（默认）
g++ -std=c++17 -O2 main.cpp

# 仅启用快速输出（嵌入式裁剪）
g++ -std=c++17 -O2 \
    -D rth_out_pro_constant_out \
    -D rth_out_pro_runtime_normal_out \
    main.cpp
每个平台都绕过了 printf / iostream 的缓冲层，直接调用系统调用 （Linux syscall、Windows WriteFile、DOS int 0x21），实现单次写入的绝对最小开销。
